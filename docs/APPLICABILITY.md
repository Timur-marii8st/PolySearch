# Научное ядро: область применимости и отказ от прогноза

Исследовательский модуль, не подключён к API рекомендаций. Прежние Monash/RAFT provisional наборы остаются раздельными. В v3 обнаружена неприемлемая экстраполяция масс при LOMO Monash; этот этап проверяет меры против неё, а не новые физические данные.

## Ограниченный молекулярный суррогат

RDKit-дескрипторы для прогноза ограничиваются минимумом/максимумом каждого признака **proper train**, постоянные признаки отображаются в наблюдаемое значение. Затем связанная линейная модель v3 получает процессные параметры и дескрипторы, обеспечивает Mn>0, Mw=Mn·Đ, Đ≥1. Не ограничиваем прогноз массы по диапазону целевых значений: не скрывать ошибку искусственным clipping метки. Обучение и alpha 1/10/100 только внутри train. Это защита от одного источника численной экстраполяции, не доказательство корректной химии.

## Domain guard (явно предварительные пороги)

Для каждого свойства: канонический SMILES должен быть известен proper train, не менее 3 групп с наблюдаемым свойством данной молекулы; каждый категориальный уровень контекста должен быть известен для её целевой головы; процессные признаки в наблюдаемом диапазоне плюс 10% диапазона (константы должны совпадать); RMS нормированной дистанции до ближайшей train-строки ≤0,5. Morgan Tanimoto сохраняется для диагностики, но высокая похожесть не снимает отказ для незнакомого SMILES. Категориальная комбинация может быть новой: отдельные уровни известны, это не доказательство совместимости рецепта. Пороги выбраны инженерно до запуска; их нельзя трактовать как установленную границу безопасного синтеза.

## Интервалы и отказ

Используем тот же proper-train суррогат и выделенные calibration-группы. Сравнение прежнего совместного 90% группового конформного интервала с отдельными marginal group интервалами 80/90%: один максимальный абсолютный остаток на каждую группу с данным наблюдаемым свойством (лог для масс и Đ). Неизмеренные цели не участвуют. Если конечный квантиль недоступен, интервал отсутствует. Маргинальный 90% уровень относится к одному свойству, не ко всем четырём одновременно. Проверяем реальные покрытия и ширины в групповой CV.

Пользователь задаёт ширину интервала; в бенчмарке иллюстративные значения: конверсия 0,20 (20 п.п.), массы отношение верхней/нижней границы ≤3, Đ ширина ≤0,30. Это не допуск заказчика. Guard + width: при отсутствии поддержки или подходящего интервала прогноз и границы не выдаются, возвращается причина. Оцениваем долю принятых наблюдаемых меток и групп, ошибки на принятых и всех данных; при отсутствии принятых ошибка null. Conditional coverage после отбора не гарантируется. Маргинальные границы связанных голов не являются совместным физически допустимым набором. Статус research_supported означает только прохождение проверок, не допуск к физическим опытам.

## Проверка переноса

LOMO: все строки одной молекулы в test, сравнить raw v3, bounded descriptor и process-only coupled. Не использовать метки held-out молекулы при подборе. Без адаптации domain обязан отказывать на всех неизвестных молекулах. Few-shot: 3 случайные группы, 8 фиксированных paired seed на молекулу, оставшиеся группы test. Сравнить bounded zero-shot на тех же test с pooled адаптацией (alpha=10). Local 3 оценивается только когда есть ≥2 группы для каждой цели; не выбирать группы с учётом будущих измерений. После адаптации исследуется только геометрическая поддержка, а не надёжность 90% интервалов (трёх групп недостаточно для такой калибровки). Результаты усредняются по парам molecule/seed, не независимые физические репликации. 

## Запуск

Выполнить ETL Monash/RAFT из [протокола v3](MOLECULAR_V3.md), затем:

```bash
python -m pip install -e ".[ml,molecular]"
python -m polysearch.ml.applicability_benchmark
```

[CI](https://github.com/Timur-marii8st/PolySearch/actions/workflows/applicability.yml) проверяет RDKit, тесты, скачивание, ETL, бенчмарк. Не обещать точность на новых материалах, безопасность или экономию. Не подключать к серверу до отдельной приёмки, QC и утверждения критериев.
