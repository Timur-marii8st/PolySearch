# PolySearch 1.0.0-beta.1 — контроль релизного кандидата

Python/PEP 440: 1.0.0b1. Версия предназначена для демонстрации и контролируемой технической приёмки в контуре одной организации. Не является подтверждённым промышленным релизом.

## Проверка кода и исправления

- Лимит JSON-тела: 256 КиБ, для CSV-импорта 8 МиБ; проверяются заголовок и фактически полученные байты. JSON обязателен для непустого POST. Лимиты не заменяют ограничения reverse proxy, concurrency и таймауты сети.
- TrustedHost: явные хосты без wildcard; отклонение чужого Origin и cross-site mutations также в локальном режиме. Сессионная CSRF-проверка сохранена.
- В ответах на ошибки схемы убраны исходные input и ctx, сохраняются loc/msg/type. Не публиковать ошибки и логи с произвольными пользовательскими полями без проверки.
- Exact GP: максимум 500 завершённых train-строк, максимум 5000 исторических и исключённых точек. При превышении явная ошибка; данные не урезаются автоматически. Не путать лимит с научно обоснованным размером выборки.
- Упаковка wheel/sdist и проверка установки в отдельное окружение. Контрольные суммы и список фактических runtime-зависимостей сохраняются как артефакты.
- CI проверяет известные advisory через pip-audit и статический анализ Bandit; не скрывать обнаруженные проблемы. Это ограниченный автоматизированный аудит, не пентест.

## Нагрузка

8 параллельных HTTP-клиентов в чистом Compose-стенде, 80 чтений, 40 записей с уникальными ID, проверка отсутствия потерь, один GP-расчёт по 40 синтетическим измерениям. Сохраняются p50/p95/max и throughput по чтению/записи. Это короткий smoke на конкретном CI runner, не SLA, не максимальная пропускная способность и не стресс-тест. Запускать только на одноразовой пустой базе с выделенной тестовой учётной записью.

## Критерии перед публикацией

- CI Python, PostgreSQL/Compose/restore, browser и benchmark без регрессий.
- Wheel/sdist устанавливаются; статические ресурсы и версия API совпадают.
- Известные уязвимости разобраны и устранены либо документированы с согласованными компенсирующими мерами.
- Техническая приёмка заказчика: TLS, мониторинг, роли, резервное восстановление, нагрузочный профиль, права на данные, конкретный LIMS и протокол физических экспериментов.

Не выкладывать релиз на PyPI, Docker Hub и не заявлять официальную промышленную готовность без отдельного решения правообладателей. Рабочий репозиторий публичный; файлы клиентов, секреты, дампы и выгрузки не включать.

## Первый прогон и исправления безопасности

Первоначальная сборка (коммит `2ddca5b`) прошла packaging, browser, Python и PostgreSQL-тесты; нагрузочный smoke сохранил все 40 записей. [Первичный аудит](https://github.com/Timur-marii8st/PolySearch/actions/runs/45896755996) выявил пять advisory в Starlette 0.50.0 (PYSEC-2026-161, PYSEC-2026-249, PYSEC-2026-248, PYSEC-2026-2281, PYSEC-2026-2280) и два предупреждения B310 в загрузчике Monash. Повышены версии FastAPI до 0.165.0 и Starlette до 1.10.0; сетевой загрузчик проверяет разрешённые HTTPS-хосты и перенаправления, добавлены тесты отклонения посторонних адресов. Важна повторная проверка аудита, реального скачивания Monash и браузера; отсутствие предупреждений не является гарантией безопасности.
