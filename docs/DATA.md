# Данные

## Контракт
Конфигурация задаёт factors (имена, границы, единицы), targets (имена, целевые границы), constraints. Записи содержат parameters, outcomes, status (completed/failed), role (train/calibration). Completed требует все целевые свойства; failed не обучает регрессию. CSV-заголовки должны совпадать с конфигурацией. Ошибка строки отменяет весь импорт.

## Открытые наборы (Monash — первый источник; остальные кандидаты)
| Набор | Задача | Ограничение |
|---|---|---|
| [Monash](https://doi.org/10.26180/29208134.v1) | Flow polymerization, конверсия | Один мономер; группировка по реакции |
| [RAFT Knowledgebase](https://zenodo.org/records/14018514) | Кинетика RAFT | Точки кривой не независимы |
| [Metallocene](https://github.com/LitaoZhu201703/ML_Metallocene_Catalyst_Design) | Активность, Mw, включение октена | Проверить пересечения и права на данные |
| [PolyMetriX](https://zenodo.org/records/14980914) | Структура → Tg | Другая постановка, не режим синтеза |
| [PolyOmics](https://huggingface.co/datasets/yhayashi1986/PolyOmics) | Расчётные свойства | Не физические синтезы |

## ETL Monash v1

Источники: [Monash v1](https://doi.org/10.26180/29208134.v1), [статья](https://doi.org/10.1039/D5RE00264H). Лицензия CC BY 4.0, с указанием авторов и изменений. Релиз фиксируется DOI, версия и хеши сохраняются в manifest.json. Исходные файлы не коммитятся.

### Запуск

```bash
python -m pip install openpyxl==3.1.5
python -m polysearch.data.monash_source
python -m polysearch.data.monash_etl \
  --mapping data/monash/mapping.mma-v1.json --folds 5
```

Файл mapping.mma-v1.json составлен по фактическому инвентарю 15 CSV и листу MMA авторской таблицы: 16 опытов в таблице, 15 CSV в релизе (отсутствует 80mma0.04). Хеши CSV и таблицы закреплены; температура перенесена из объединённых ячеек. Учитываются точные варианты названия столбца conversion (включая manual conversion и ведущий пробел). Шаблон mapping.template.json намеренно остаётся незаполненным.

### Научная постановка

MMA: признаки — температура (°C), CT/CM (отношение концентраций агента переноса цепи и мономера), время пребывания (мин); цель — конверсия [0,1]. CT/CM не является долей инициатора. Пока рассматриваем прогноз точек кинетических кривых; для оценки стоимости BO нужно отдельно выбрать экспериментальный endpoint и определить единицу бюджета.

Авторская статья описывает возможные скачки между timesweep-сериями и отрицательную конверсию. Нельзя исправлять их усреднением либо автоматически объявлять позднюю серию достоверной без проверки протокола. Первичная разметка имеет статус provisional: фильтр Status=Timesweep, tres в минутах, конверсия в долях ([документация платформы, Table S14](https://doi.org/10.1039/D2DD00035K)); физические диапазоны и явные исключения. Возможные скачки >5 процентных пунктов при близком времени пребывания отмечаются эвристически, а не удаляются автоматически; необходима проверка специалистом. Разметка допускает документированные исключения диапазонов строк. Невалидные численные значения отбрасываются с причиной, без заполнения вымышленными данными.

### Подготовленные артефакты

- mma_conversion.csv — признаки, цель, experiment_id, split_group, fold, источник, номер исходной строки, SHA256.
- rejected.csv — исключённые строки с причинами.
- quality.json — количество принятых и исключённых измерений, независимых реакций и условий, диапазоны признаков и цели, дубликаты, распределение групп по фолдам, контрольная сумма таблицы и разметки.

Разбиение детерминировано по seed. Все строки одной реакции и реплик с одинаковыми температурой и CT/CM относятся к одному фолду. При недостатке уникальных условий ETL останавливается. В ML-оценке нужны внешние групповые фолды, а подбор гиперпараметров и калибровка — только внутри обучающей части. Не считать число NMR-точек числом независимых синтезов.

Частично наблюдаемые Mn/Mw/Đ требуют отдельного контракта. Не считать предварительную таблицу полностью подтверждённой химической разметкой; не импортировать эту таблицу в текущий API как независимые физические trials. Не размещать закрытые клиентские данные в Git.
