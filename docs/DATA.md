# Данные

## Контракт
Конфигурация задаёт factors (имена, границы, единицы), targets (имена, целевые границы), constraints. Записи содержат parameters, outcomes, status (completed/failed), role (train/calibration). Completed требует все целевые свойства; failed не обучает регрессию. CSV-заголовки должны совпадать с конфигурацией. Ошибка строки отменяет весь импорт.

## ETL Monash
Зафиксировать релиз и лицензию, сохранить хеши raw-файлов. Выбрать мономер и endpoint. Нормализовать температуру, отношение агента переноса цепи к мономеру CT/CM и время пребывания. Сохранить experiment_id, единицы, протокол, источник, причины отбраковки. Не путать CT/CM с долей инициатора. Train/test разделять по независимой реакции. Частично наблюдаемые Mn/Mw/Đ требуют обновления текущего контракта.

Не размещать закрытые клиентские данные в Git. Лицензии и пригодность каждого набора проверить перед коммерческим использованием.
