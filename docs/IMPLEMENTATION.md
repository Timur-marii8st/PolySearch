# Реализация PolySearch v0.1.0

Самостоятельное программное ядро по спецификации репозитория, не перенос архивного исходного кода. Документ PROJECT_MAP описывает предшествующий демонстратор; его результаты не относятся автоматически к новой реализации.

## Запуск
Python 3.11 или 3.12.
```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
python -m pytest -q
python -m uvicorn polysearch.api:create_app --factory --host 127.0.0.1 --port 8000
```
Рабочее пространство: http://127.0.0.1:8000/ ([WEB_UI](WEB_UI.md)). Swagger: http://127.0.0.1:8000/docs. База по умолчанию polysearch.sqlite3; переменная POLYSEARCH_DB меняет путь. Использовать один процесс, без --workers. Локальная версия без авторизации.

## Демо-цикл
POST /api/demo с {"n_initial":12}; если проект существует, явно указать reset:true. POST /api/recommend с {"batch_size":1}; POST /api/simulate с ID рекомендации. Затем снова запросить рекомендацию. Искусственная функция не моделирует химический процесс.

## Реальные данные
POST /api/config с {"config":{"factors":[{"name":"x","lower":0,"upper":1}],"targets":[{"name":"y","lower":0.8,"scale":0.2}]}}.
POST /api/import.csv с JSON {"csv":"x,y\n0.1,0.2\n0.5,0.7"}. CSV целиком проверяется до сохранения. GET /api/export.json выгружает состояние. POST /api/results принимает фактические измерения.

## Ограничения
- GP с Matérn 5/2 и независимыми выходами, MC-EI, maximin cold start, линейные ограничения и разнообразие серии.
- Модельная вероятность не калибрована. Split conformal только для отдельных выходов; нет гарантии покрытия адаптивно выбранных точек.
- Хранилище одного проекта, блокировка внутри процесса. После новой записи весь список рекомендаций сбрасывается.
- Только численные факторы и полные измерения; конечный пул кандидатов не гарантирует глобальный оптимум. Нет аппаратного управления, LIMS, многопользовательской авторизации или подтверждения экономии. Monash MMA обработан и исследован отдельно; строки кинетических кривых нельзя загружать как независимые trials. Модель текущего API обучается по запросу, архивные веса не применяются автоматически.
- Зависимости верхнего уровня закреплены; полный lock-файл транзитивных зависимостей предстоит создать.
