# ML-ядро

## Формализация
x — управляемые численные факторы, y — измеренные свойства. Допустимая область определяется границами и Ax ≤ b. Целевая потеря — среднее нормированное нарушение диапазонов свойств:

L(y) = mean_j((max(l_j − y_j, 0) + max(y_j − u_j, 0))/s_j).

Для односторонних требований отсутствующая граница не даёт штрафа; масштабы должны быть положительными.

## Модели
По карте MVP: независимый sklearn GaussianProcessRegressor для каждого свойства, ConstantKernel × Matérn 5/2 (ARD) + WhiteKernel, normalize_y=True, alpha=1e-8. Факторы нормируются в [0,1]. Минимум 3 различные завершённые train-точки — техническое условие, не доказательство достаточного объёма данных.

## Оптимизация
До первого попадания в целевые диапазоны: Monte Carlo expected improvement E[max(L_best − L(Y(x)),0)]. После измеренного попадания используется модельная вероятность повторного достижения всех целей. Пул по умолчанию до 1536 точек, 128 MC-выборок; Latin Hypercube и локальные кандидаты. Проверка линейных ограничений, исключение выполненных точек. Серия до 3 кандидатов — жадная эвристика разнообразия, не точный совместный q-EI.

## Неопределённость
На отдельной calibration-выборке r_i = |y_i − μ_i|/σ_i. Ранг ceil((n+1) × confidence); если он превышает n, конечный conformal-интервал не выдаётся. Иначе μ ± qσ. Это маргинальное покрытие при обменности данных, не гарантия для адаптивно выбранных точек или совместного выполнения всех целей.
