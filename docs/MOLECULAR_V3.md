# ML Engine v3 — молекулярное представление и согласованные свойства

Исследовательский модуль, не замена рабочего API. Данные Monash и RAFT используются раздельно, прежние численные QC сохраняются.

## Молекулярные структуры

Registry data/molecular/monomers-v1.json: BA/MMA/VA, 16 RAFT-мономеров. Коды RAFT сверяются при запуске с полным листом Legend for Abbreviations закреплённого XLSX (SHA256 из raft_etl). SMILES получены из названий, не подтверждены по сертификатам поставщика/CAS и экспертной оценке изомерии. В RDKit 2025.9.6 проверяются валидность и уникальность канонических SMILES. Дескрипторы: MolWt, MolLogP, TPSA, HBD, HBA, вращаемые связи, кольца, ароматические кольца, fraction Csp3, тяжёлые атомы, гетероатомы, MolMR. RAFT-агент и растворитель — категориальные признаки, их молекулярные структуры пока не кодируются. [RDKit documentation](https://rdkit.org/docs/GettingStartedInPython.html).

## Согласованная модель свойств

Сравниваем четыре режима: численные условия + контекст; one-hot мономер + контекст; дескрипторы + контекст с независимыми головами; дескрипторы + связанные головы масс. Все преобразования обучаются на train. Конверсия — отдельная Ridge-голова с ограничением [0,1]. Для масс совместная квадратичная задача с наблюдаемыми масками и Ridge-регуляризацией:

- log(Mn)=a(x)
- log(Mw)=a(x)+b(x)
- log(Đ)=b(x)

Один коэффициентный вектор для a и b, ошибки всех доступных наблюдений входят в fit. Предсказание: b=max(0,b), Mn=exp(a), Đ=exp(b), Mw=Mn·Đ. Латенты численно ограничиваются в log-пространстве. Не подменять отсутствие наблюдений синтетикой; NMR/SEC отдельны, не объединять по близости времени. Это структурированная линейная многовыходная модель, не нейросеть с совместным обучением кинетики и масс. Тождество гарантируется алгебраически, но точность зависит от данных.

## Проверка

Monash: прежние 5 групповых фолдов для всех четырёх свойств; RAFT: 5 групповых фолдов по комбинации рецепта. Три внутренних фолда выбирают общий alpha из 0.1/1/10/100 по средней group macro MAE в преобразованном пространстве (конверсия и log масс/Đ). Для сравнения точности приводим Macro MAE в исходных единицах и R². Проверка согласованности по всем строкам, включая ненаблюдавшиеся головы; это предсказания, не новые наблюдения. Дополнительно leave-one-canonical-SMILES-out: целиком исключается молекула, никакая её группа не участвует в подборе. Morgan radius=2/1024 bits используется только для оценки ближайшей структурной похожести (Tanimoto), не для обучения. One-hot неизвестного мономера кодируется нулём, а не произвольной известной категорией. Отдельная чувствительность Monash без всех 11 flagged реакций; не выдавать исключения за экспертную курацию.

## Неопределённость

Отдельный split conformal на outer train: минимум 9 групп калибровки, остальные proper train; гиперпараметры заново подбираются только на proper train. Масштаб ошибок по каждому свойству — медиана абсолютного остатка proper train с нижней границей 1e-6. Максимальный нормированный остаток по всем наблюдаемым значениям группы образует один calibration score. 80% и 90% квантили конечной выборки; нет конечного квантили — нет конечного интервала. В исходных единицах bounds для конверсии обрезаются в [0,1], Đ≥1. Проверяем покрытие целых групп всех наблюдаемых целей, покрытие отдельных целей и ширину. Интервалы — маргинальные границы совместного множества, не независимые допустимые комбинации Mn/Mw/Đ. Обменность групп не установлена, не обещать покрытие незнакомой молекулы/адаптивного опыта. Калибровка только в group CV, не на LOMO.

## Воспроизведение

```bash
python -m pip install -e ".[ml,molecular]"
python -m polysearch.data.monash_source --subset kinetics --root data/raw/monash-kinetics-v1
python -m polysearch.data.monash_multimonomer
python -m polysearch.data.raft_source
python -m polysearch.data.raft_etl
python -m polysearch.ml.molecular_benchmark
```

Отдельный CI Molecular ML v3. RDKit не включён в базовые серверные зависимости и не охвачен существующим серверным pip-audit. Перед deployment нужен отдельный аудит и независимая валидация. RAFT по-прежнему nominal time, собственный provisional QC, не опубликованная кураторская выборка. Не заявлять экспериментальную/экономическую эффективность без физического пилота.
