В RAFT molecular_coupled снижает macro MAE конверсии с 16,20 п.п. (one-hot) до 11,95 п.п. При этом Mn/Mw/Đ не улучшаются устойчиво. В Monash с двумя обучающими молекулами перенос по дескрипторам резко ухудшает массы: macro MAE Mn около 219 тыс. г/моль, Mw около 438 тыс. г/моль. Это неприемлемая экстраполяция. Не выбирать v3 как автоматический универсальный оптимизатор. Требуется явный applicability domain, отказ от прогнозов вне области, дополнительная экспериментальная адаптация. Morgan Tanimoto диагностический, ещё не критерий отказа.

## Решение

Рабочий API и пилотный GP не менялись. Сохранить v3 исследовательским кандидатом; следующий этап — applicability domain с явным отказом вне области, адаптация на новых группах, оценка OOD и безопасное включение только в предварительный исследовательский интерфейс. Не выдавать интервалы за гарантию, не использовать для физического исполнения. Экспертная проверка исходных кривых, CAS/реагентов, точного времени RAFT и внешний проспективный пилот всё ещё необходимы.
