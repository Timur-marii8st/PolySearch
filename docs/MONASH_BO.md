# Архивная проверка BO: Monash MMA v1

**Фактические результаты:** [MONASH_BO_RESULTS](MONASH_BO_RESULTS.md).

## Постановка (фиксируется до запуска)

- Источник: Monash MMA v1, DOI 10.26180/29208134.v1, CC BY 4.0, атрибуция в data/monash/README.md. Проверяется SHA-256 подготовленной таблицы.
- Один запрос = одна ранее не наблюдавшаяся независимая реакция. Признаки: температура и CT/CM. Время пребывания фиксировано приближённо: берём медиану фактически измеренных конверсий в окне 6.0 ± 0.25 минуты. Нет интерполяции или синтетической подстановки результата. Если окна нет, реакция исключается с причиной. Источники строк сохраняются.
- Конечный пул содержит только архивные условия; его геометрия известна политикам, а метки закрыты до выбора. На каждый запрос раскрывается только endpoint выбранной реакции. Все политики получают одинаковые 3 случайно выбранных стартовых реакции; бюджет 10 реакций с учётом стартовых. 64 одинаковых seed для каждой политики. Повторных запросов нет.
- Цель максимизации — конверсия; иллюстративный порог 15% (не производственное требование), дополнительно достижение уровня не более чем на 1 п.п. ниже наблюдаемого максимума пула (только оценка).
- Отдельный анализ чувствительности без MMA-13 и MMA-16. Все правила зафиксированы в replay.py. Это не новый независимый тест: архив уже использовался для оценки моделей.

## Стратегии

| Политика | Алгоритм |
|---|---|
| random | Равномерно случайный выбор из остатка пула |
| maximin | Максимальная минимальная дистанция до наблюдавшихся условий |
| ridge_greedy | Ridge alpha=1, максимальный прогноз |
| gp_ei | GP Matérn 5/2 + аналитический EI относительно лучшего наблюдаемого результата |
| ridge_residual_gp_ei | Ridge как средний тренд и GP на остатках, аналитический EI |

Геометрия нормируется по известным входам всего конечного пула, без целевых значений. GP с фиксированным prior: масштаб сигнала 0.05, шум измерений 0.02 (доли конверсии), длина шкалы 0.35 нормированных входов. Это заранее выбранные инженерные параметры для сравнения, не подтверждённые оценки шума. GP posterior использует дисперсию скрытой функции, а не шум наблюдений. EI с наблюдаемым incumbent не является точным noisy EI. В гибриде не учитывается неопределённость оценки тренда Ridge.

## Метрики

- Best-so-far и simple regret (разница с лучшим измеренным endpoint в пуле) по каждому бюджету.
- Доля траекторий, достигших 15% и уровня в пределах 1 п.п. от oracle.
- Число запросов до достижения порога: медиана только среди успешных, отдельно количество неуспехов и среднее capped cost (неуспех = budget+1).
- Парные разности best-so-far относительно random при одинаковом начальном плане.
- Все запуски и траектории сохраняются; случайные seed не являются независимыми физическими репликациями. Нет теста статистической значимости и доказательства реальной экономии.

## Воспроизведение

```bash
python -m pip install -e ".[ml]"
python -m polysearch.data.monash_source --subset mma
python -m polysearch.data.monash_etl --mapping data/monash/mapping.mma-v1.json --folds 5
python -m polysearch.bo.replay
```

Артефакты report.json, traces.csv и quality.json публикуются в GitHub Actions. Сценарий — оценка алгоритма, не инструкция для физической установки. Для пилота необходимы независимые проспективные реакции, согласованный endpoint, фактическая цена и время каждого опыта, контроль качества и технологические ограничения. Нельзя переносить архивный эффект на производство.
