# Сравнение ML на Monash MMA v1

**Фактические результаты:** [MONASH_ML_RESULTS](MONASH_ML_RESULTS.md).

Цель — прогноз конверсии в долях для ранее не измеренного набора условий. Это не задача доказательства уменьшения числа физических синтезов.

## Протокол

- DOI 10.26180/29208134.v1, исходные хеши, 785 предварительно очищенных строк, 15 групп условий. Таблица сверяется с SHA256 из quality.json. MMA-1 отсутствует.
- Признаки: температура, CT/CM, время пребывания. ID, номер скана, timesweep и информация о целевой переменной не используются как признаки.
- 5 фиксированных внешних групповых фолдов. Все строки группы и независимой реакции только в одном фолде. В каждом внешнем train — 3 внутренние группы фолдов для выбора гиперпараметров Ridge, CatBoost и кинетической модели. GP использует фиксированное семейство ядра и оптимизирует гиперпараметры только при fit на outer train. Нормализация обучается на train. Все модели дают прогноз для одних и тех же наблюдений.
- Главная метрика — macro MAE по группам условий (каждая группа имеет одинаковый вес). Дополнительно MAE, RMSE, R² по строкам и group-macro RMSE. Ridge, CatBoost и кинетическая модель обучаются с весами, уравнивающими вклад групп; точный sklearn GP использует обычный likelihood строк. Все прогнозы ограничиваются физическим диапазоном [0,1].
- Основной эксперимент использует все 15 групп; отдельно повторяем протокол без MMA-13 и MMA-16, отмеченных QC. Это анализ чувствительности, не независимый тест.

## Модели
| Модель | Реализация |
|---|---|
| Ridge | StandardScaler + Ridge, alpha по внутреннему group CV |
| CatBoost | глубина 3/5, 200/500 итераций, learning rate 0.05 |
| GP | StandardScaler + Constant × Matérn 5/2 ARD + WhiteKernel |
| Kinetic | X=1-exp(-k_eff t); log(k_eff) зависит от обратной температуры и log(1+CT/CM/0.05); неотрицательный температурный коэффициент; регуляризация по внутреннему group CV |

Кинетическая формула — физически мотивированный эмпирический baseline с эффективной константой скорости. Это не полный кинетический механизм свободнорадикальной полимеризации.

## Интервалы

1. GP nominal 90%: прогноз распределения наблюдений, эмпирическая доля попаданий и ширина; не калиброванная гарантия.
2. Group split conformal 80%: отдельный GP в каждом внешнем фолде, четыре случайно выбранные калибровочные группы внутри outer train, fit на остальных восьми. На группу — максимальный нормированный остаток. Квантиль конечной выборки; при n=4 90%-ный конечный квантиль недоступен. Измеряем попадание отдельных строк и целых кривых. Обменность групп не доказана. Нет обещания покрытия адаптивно выбранных условий.

Модель с наименьшей внешней ошибкой — кандидат для следующего этапа, а не подтверждённый победитель на независимом будущем тесте.

## Воспроизведение

```bash
python -m pip install -e ".[ml]"
python -m polysearch.data.monash_source --subset mma
python -m polysearch.data.monash_etl --mapping data/monash/mapping.mma-v1.json --folds 5
python -m polysearch.ml.benchmark
```

Артефакты: report.json (включая параметры, метрики каждого фолда, предупреждения и версии библиотек), oof_predictions.csv и quality.json. Сохраняются в GitHub Actions. Исходные данные остаются в локальном игнорируемом каталоге; атрибуция в data/monash/README.md.
