# Расширение научных данных PolySearch

## Источники и протокол

Monash v1, DOI https://doi.org/10.26180/29208134.v1, CC BY 4.0, Asghar, Zhang, Junkers, Jafari; статья https://doi.org/10.1039/D5RE00264H. Схема измерений и единицы: https://doi.org/10.1039/D2DD00035K, SI Table S14. 47 CSV и авторская таблица, фиксированные имена, ID, размеры, MD5 и SHA256. Проверенные BA/VA mappings построены по таблице авторов и точным CSV headers. Для VA пустые температурные ячейки восстановлены из явно совпадающих кодов папок; дополнительные эксперименты BO имеют отдельную метку, один общий код 85va0.2 не дублирован. Нет CSV MMA-1. VA-11 отсутствует в таблице исходных реакций; не реконструировать данные из PNG. История MMA сохранила прежнюю обработку.

NMR: Status=Timesweep, tres (мин), физическая конверсия [0,1]. SEC: собственный tres_GPC (мин) и GPC_number, измеренные Mn/Mw (г/моль) и Đ; не использовать Mn theory. Нет искусственной стыковки NMR и SEC по строке или близости времени. Проверять положительные массы, Mw≥Mn, Đ≥1, согласованность Đ с Mw/Mn (допуск 5% или 0,05); совпадающие инъекции дедуплицируются, конфликтные исключаются. Это численный QC, не проверка хроматограмм. Отдельно сохранять источник, строку, хеш, ID реакции, группы условий и fold. Пропущенные цели остаются пустыми. Все таблицы provisional.

Три VA-BO реакции не содержат колонок SEC. Непригодные инъекции: BA 5, VA 20. Не считать 2558 наблюдений числом независимых реакций. Возможные скачки требуют экспертной проверки и анализа чувствительности; этот benchmark использует все предварительно принятые наблюдения, отдельный sensitivity по 11 флагам пока не проведён.

## Предсказание четырёх свойств

MaskedPropertyRegressor: отдельная голова Ridge для каждой наблюдаемой цели, без импутации, признаков-утечек или использования измеренного свойства как входа. Преобразования: обратная абсолютная температура, log1p(CT/CM/0.05), log1p(время); scaler только на train; логарифм положительных масс/Đ. Общая модель добавляет one-hot идентификатор мономера и взаимодействия с численными признаками. У каждой головы свои метки и группы. Предсказания ограничены диапазоном [0,1] или положительны (Đ≥1); совместная согласованность Mw≥Mn, Đ=Mw/Mn не гарантирована. Модель не внедрена в рабочий API.

Внешние фиксированные 5 групповых фолдов (группы общие для NMR и SEC), alpha выбирается внутри train в 3 групповых фолдах. Метрика Group Macro MAE (каждая группа одинаково важна).

| Свойство | Наблюдения / группы | Локальный Ridge | Общий с ID мономера | Общий без ID |
|---|---:|---:|---:|---:|
| Конверсия (п.п.) | 2271 / 47 | 4.52 | 4.48 | 8.43 |
| Mn (г/моль) | 287 / 44 | 359.2 | 359.9 | 796.5 |
| Mw (г/моль) | 287 / 44 | 546.8 | 540.2 | 1082.2 |
| Đ (безразм.) | 287 / 44 | 0.093 | 0.094 | 0.103 |

Общий с идентичностью немного улучшает конверсию и Mw; Mn и Đ не улучшаются. Смешивание без идентичности ухудшает результат. Не утверждать статистически значимое преимущество или точность на ином технологическом контуре.

## Переносимость между мономерами

Leave-one-monomer-out: zero-shot обучается только на остальных мономерах и не использует идентичность неизвестного мономера. Адаптация: 3 группы нового мономера, восемь парных seed, остальные группы — test. Сравнение на тех же test-группах; few-shot alpha=1 фиксирован. Конверсия, Group Macro MAE в п.п.:

| Мономер | Zero-shot на тех же test-группах | Локальная 3 группы | Перенос + 3 группы |
|---|---:|---:|---:|
| BA | 17.05 | 5.81 | 5.28 |
| MMA | 10.76 | 7.88 | 7.34 |
| VA | 9.50 | 10.03 | 7.77 |

На всех трёх мономерах адаптация улучшила среднюю ошибку относительно zero-shot и локальной модели на трёх группах. На молярных массах и Đ нет универсального преимущества. Это исследование в одной лаборатории, не подтверждение переносимости на независимый новый источник. Few-shot группы не являются будущими независимыми экспериментами. Нельзя обещать, что трёх реакций всегда достаточно.

## Отдельная база RAFT

Ringleb, Köster, Zechel, Schubert, Digital Discovery 2025, DOI https://doi.org/10.1039/D5DD00177C. Закреплён архив https://doi.org/10.5281/zenodo.15230215 v1.0.0, CC BY 4.0. См. [описание источника](../data/raft/README.md). Строгий первоначальный фильтр явных положительных флагов дал один пригодный опыт, поэтому не считать его опубликованной выборкой 234 кривых. Дополнительно реализован предварительный численный QC немаркированных, явно не отклонённых записей; хранить строгую и provisional выборки отдельно. Точное время из отдельного листа ещё не сопоставлено — используется nominal_time_h. Не смешивать с Monash; независимый RAFT baseline на кодах рецепта, без обещания внешней переносимости. [Отдельный CI](https://github.com/Timur-marii8st/PolySearch/actions/runs/46006836937).

Следующий этап: экспертный QC кривых, согласованная обработка точного времени RAFT, оценка чувствительности по всем flagged, совместно согласованные физические ограничения масс, неопределённость для четырёх целей и независимый проспективный пилот.

Фактические результаты отдельного RAFT baseline: [RAFT_RESULTS](RAFT_RESULTS.md). Набор численного QC — 2006 срезов, 442 ID опыта, 299 групп рецептов; не авторская отобранная выборка.
