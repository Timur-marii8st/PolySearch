# RAFT: результаты предварительной обработки и baseline

[Артефакты фактического прогона](https://github.com/Timur-marii8st/PolySearch/actions/runs/46006836937/artifacts/15201847638); [машиночитаемая сводка](../reports/raft-provisional-v1.json). Источник: Zenodo DOI 10.5281/zenodo.15230215 v1.0.0, CC BY 4.0, атрибуция и статья в [описании источника](../data/raft/README.md).

- 540 строк с идентификатором образца: 1 явно положительная отметка, 50 явных отклонений, 488 немаркированных, 1 неоднозначная.
- Строгий явный subset: 1 пригодный временной срез одного опыта. Не воспроизводит авторские 234 отобранные кинетики.
- Предварительный численный QC: 2006 срезов (442 experiment IDs, 299 групп рецептов), включая 2005 срезов немаркированных реакций. 16 кодов мономеров, 7 кодов RAFT-агентов, 3 кода растворителей. Непригодные и отсутствующие измерения не имитируются и не дополняются.
- 1874 измерения конверсии, 330 Mn, 327 Mw, 327 Đ. Эти количества перекрываются в строках. 2449 временных точек с признаками SEC QC исключены из соответствующих целей; 245 записей конверсии отклонены по диапазону/отсутствию интеграла.
- Номинальные часы, не восстановленное точное время. Хранить отдельно от Monash (иная химия и протокол). Численный QC не означает подтверждение достоверности немаркированных измерений авторами.

## Групповой baseline
Пять внешних GroupKFold, три внутренних для alpha; одинаковые группы рецептов не пересекаются между train/test. Вход: log1p(номинальные часы), плюс one-hot код мономера, RAFT-агента, растворителя для recipe-модели. Метрика: group macro MAE, группы равновесны. Для масс и Đ логарифмическая цель. Модели независимы.

| Цель | Наблюдения / группы | Только время | Время + рецепт | R² recipe |
|---|---:|---:|---:|---:|
| Конверсия, п.п. | 1874 / 295 | 16.63 | 10.39 | 0.677 |
| Mn, г/моль | 330 / 126 | 6656.8 | 4066.6 | 0.491 |
| Mw, г/моль | 327 / 123 | 6752.7 | 3628.0 | 0.627 |
| Đ, безразм. | 327 / 123 | 0.183 | 0.107 | 0.665 |

Добавление кодов рецепта уменьшает ошибку для всех четырёх целей. R² относится к объединённым OOF-строкам, не является показателем переноса на новые мономеры или другую лабораторию. Результат разведочный, на provisional наборе, не подтверждение авторской курации или эффективности синтеза. Не использовать для физического проведения реакции без согласования технологом.
