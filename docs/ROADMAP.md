# Дорожная карта

| Этап | Результат | Критерий готовности |
|---|---|---|
| 1. Документация | README и технические спецификации | Документация в main, ссылки работают |
| 2. Код | Перенос разрешённых исходников или воспроизводимая реализация | Локальный запуск, зависимости, тесты и CI |
| 3. Данные | Monash ETL, один мономер, конверсия | Источник, единицы, experiment_id, отчёт импорта |

| 5. BO | Архивная проверка | Скрытые метки, единый бюджет, полные результаты |
| 6. Интерфейс | Локальное рабочее пространство | Браузерные сценарии и API |
| 7. Подготовка пилота | Кампании, согласование, снимки модели и учёт затрат | Программные и браузерные тесты; физический пилот отдельно |
| 8. Серверная инфраструктура | PostgreSQL, контейнеры, сессии, RBAC, backup/restore | Интеграционный CI |
| 9. Обмен и подготовка B2B | Универсальный JSON LIMS/ELN, демонстрация, документы пилота | Программная проверка и согласование с заказчиком |
| 10. Beta-кандидат | Аудит, упаковка, нагрузочный smoke | CI и пакет; внешняя приёмка отдельно |
| 11. Научное ядро v2 | Гибриды, BoTorch, многокритериальный и cost-aware BO | Воспроизводимое исследование прежнего архива и синтетической задачи |
| 12. Независимые данные | QC, новые мономеры и источники, проверка переносимости | Новая независимая выборка |
| 13. Научное ядро v3 | RDKit, связанные свойства и групповая неопределённость | Проверенный исследовательский benchmark |
| 14. Область применимости | OOD, адаптация, отказ от ненадёжного прогноза | Воспроизводимая проверка на отложенных молекулах |
| 15. Планирование научных данных | Learning curves, необходимая калибровка, протокол независимых опытов | Измеримые цели точности и план сбора данных |
| 16. Приёмка и эксплуатация | TLS, безопасность, нагрузка, коннектор заказчика | Приёмка и физический пилот |
