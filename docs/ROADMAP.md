# Дорожная карта

| Этап | Результат | Критерий готовности |
|---|---|---|
| 1. Документация | README и технические спецификации | Документация в main, ссылки работают |
| 2. Код | Перенос разрешённых исходников или воспроизводимая реализация | Локальный запуск, зависимости, тесты и CI |
| 3. Данные | Monash ETL, один мономер, конверсия | Источник, единицы, experiment_id, отчёт импорта |
| 4. ML | Ridge/CatBoost/GP | Общие групповые splits, MAE/RMSE, покрытие |
| 5. BO | Архивная проверка | Скрытые метки, единый бюджет, полные результаты |
| 6. Интерфейс | Локальное рабочее пространство | Браузерные сценарии и API |
| 7. Подготовка пилота | Кампании, согласование, снимки модели и учёт затрат | Программные и браузерные тесты; физический пилот отдельно |
| 8. Промышленная эксплуатация | LIMS, права, версии, мониторинг | Прослеживаемость и резервное восстановление |
