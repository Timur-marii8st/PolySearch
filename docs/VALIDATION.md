# Проверка качества

По предоставленной карте v0.1.0: 18 тестов API/движка, 20 синтетических запусков по 24 опыта, первые 8 общие. GP достиг цели 20/20, random 1/20, LHS 0/20. Эти результаты не воспроизведены в данном репозитории и не доказывают промышленную эффективность.

## Протокол
- Программные тесты: атомарность импорта, перезапуск, ограничения, устаревшие ID, изоляция calibration от fit/acquisition.
- Реальные данные: GroupKFold по независимым экспериментам, настройка только внутри train; MAE/RMSE по свойствам и покрытие/ширина интервалов.
- Архивный BO: конечный пул реально измеренных кандидатов, скрытые ответы до выбора. Сравнить с random и согласованным DoE при одинаковом бюджете. Не заменять неизвестные измерения прогнозом суррогата.
- Проспективный пилот: предварительно фиксировать целевые свойства, baseline, бюджет, подтверждающие повторы, ограничения, стоимость и критерий успеха. Учитывать все неуспешные серии.

Отчёты синтетической, архивной и физической проверки публикуются отдельно. Не заявлять 50–70% экономии либо ускорение 10–25× без независимого реального подтверждения.
