# Локальный веб-интерфейс

PolySearch UI — статические HTML/CSS/JS-файлы, обслуживаемые FastAPI из пакета polysearch. Не нужен Node.js, CDN или API-ключи. Все операции используют существующие маршруты API.

## Запуск

```bash
python -m pip install -e .
python -m uvicorn polysearch.api:create_app --factory --host 127.0.0.1 --port 8000
```

Открыть http://127.0.0.1:8000/ . Swagger остаётся по /docs.

## Сценарии

- Обзор: режим проекта, счётчики всех записей, завершённых train/calibration и достигших цели train; график выбранного свойства и целевой диапазон.
- Следующий опыт: до трёх кандидатов, точные параметры, прогнозы, тип интервала, явно некалиброванная модельная вероятность, предупреждения модели. При cold start прогнозов нет.
- Журнал: ручной ввод, связь с актуальной рекомендацией, статусы, роль, примечание, CSV-импорт, шаблон заголовков, экспорт JSON, фильтрация и страницы.
- Настройки: численные факторы, цели и масштабы, seed, уровень интервала и линейные ограничения JSON. Замена проекта требует подтверждения; экспортируйте историю заранее.
- Проверка качества: сведения текущего расчёта отдельно от исторических ML/BO-результатов Monash.

Демо запускает синтетический проект и разрешает симуляцию. В реальном режиме симуляция недоступна, результаты вводит пользователь. После нового измерения рекомендации становятся недействительными; расчёт запускается заново. Не импортировать коррелированные строки Monash как независимые физические опыты.

## Проверка

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
python -m pip install playwright==1.56.0
python -m playwright install chromium
# Запустить отдельный пустой тестовый сервер с POLYSEARCH_DB=/tmp/polysearch-ui-test.sqlite3
python tests/browser/smoke.py
```

Browser workflow создаёт отдельную SQLite БД, выполняет пользовательские сценарии на Chromium и сохраняет скриншоты.

## Границы

Это локальное однопользовательское рабочее пространство, не личный кабинет с регистрацией, разграничением ролей или облачным хостингом. Использовать один процесс и bind 127.0.0.1. Нет промышленного управления, автоматического исполнения рекомендаций, редактирования истории, восстановления из JSON и интеграции с LIMS. Универсальный API использует GP; архивный Ridge/BO-бенчмарк не подменяет эту модель. Для реальных режимов обязательны проверка технологом и независимая валидация.
