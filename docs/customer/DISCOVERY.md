# Анкета discovery / техническая встреча

Цель — определить, есть ли платящая задача, данные и технологическая возможность контролируемого пилота. Заполняется вместе с заказчиком; не собирать коммерческие секреты до согласования режима обмена.

| Блок | Вопросы / артефакты |
|---|---|
| Бизнес | Какой материал и измеримое свойство оптимизируются? Кто владеет задачей и бюджетом? Как принимается решение о запуске следующего опыта? |
| Экономика | Сколько стоят сырьё, установка, измерения и труд? Каковы затраты и сроки типового цикла? Кто фиксирует неудачные попытки? |
| Данные | Число независимых реакций и повторов, факторы, цели, единицы, пропуски, признаки QC, первичные ID, схема CSV/JSON и пример обезличенных записей |
| Технология | Диапазоны параметров, физические ограничения, метод измерения, независимый повтор, допуск ответственного специалиста, причины остановки |
| Baseline | Каков действующий способ выбора опытов? Есть ли зафиксированный бюджет, одинаковая история и независимые ветки? |
| LIMS/ELN | Продукт/версия, ответственный, форматы экспорта, устойчивые ID, API и ограничения доступа, структура результатов и единицы |
| ИТ/ИБ | Локальный или серверный контур, TLS, роли, требуемая изоляция, данные, секреты, журналирование, SSO/MFA, backup/restore, регламент удалённого доступа |
| Закупки | Лицо, принимающее решение, юридический формат пилота, бюджет и срок согласования, условия перехода на коммерческий договор |

## Go/no-go
- Идентифицируемая дорогая задача с измеримыми свойствами и доступным ответственным технологом.
- Достаточно независимых измерений либо план сбора данных; не подменять независимые реакции спектральными строками.
- Согласуемое безопасное пространство опытов, контроль измерений и baseline.
- Выделенный бюджет/установка и возможность измерить фактические затраты.
- Допуск ИТ/ИБ и права на данные, договорённость о конфиденциальности.

При отсутствии этих условий — сначала совместный аудит данных или небольшая подготовительная работа, не обещать физический эффект.
