Обмен с лабораторией

Экспорт согласованных заданий и проверка результатов перед включением в кампанию.

Файловый обмен, не прямое управление оборудованием. Проверка хеша не является электронной подписью. Единицы должны совпадать с протоколом; преобразования автоматически не выполняются.

1. Согласованное задание

Только утверждённые, ещё не выполненные планы активной кампании.

2. Входящие измерения

Выберите файл для предварительного просмотра.

Файл должен содержать версию схемы, внешний ID, хеш задания, фактические параметры, измерения, валюту, стоимость, время и первичный источник.
