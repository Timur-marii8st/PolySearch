Настройки проекта

Определите управляемые факторы и измеряемые свойства.

Сервис хранит один проект. Сохранение новой конфигурации заменяет текущий проект и его историю только после явного подтверждения. Перед этим экспортируйте JSON.

Факторы

Имена латиницей: например temperature_c. Нижняя граница должна быть меньше верхней.

Целевые свойства

Можно оставить одну из границ пустой. Масштаб нормирует отклонение от цели и должен быть положительным.

Дополнительные настройки

Пример: [{"coefficients":{"factor_a":1,"factor_b":2},"upper":3}]. Математическая допустимость не означает технологическую безопасность.
